## 1. 공통 앱 셸

```text
┌────────────────────────────────────────────────────────────────────┐
│ 개발 도면 사전 검토                         로컬 모드 ●  도움말   │
├───────────────┬────────────────────────────────────────────────────┤
│ 지식 가져오기 │ 페이지 제목 / 프로젝트 선택                       │
│ 규칙 카탈로그 │ ───────────────────────────────────────────────── │
│ 도면 검사     │                                                    │
│ 설정·진단     │               현재 화면 내용                       │
│               │                                                    │
├───────────────┴────────────────────────────────────────────────────┤
│ 데이터: 로컬 저장 · 모델 프로파일 · 앱 버전                       │

```

- 건너뛰기 링크는 본문 시작으로 이동한다.
- 좌측 탐색 순서는 고정하며 현재 화면을 텍스트와 아이콘으로 표시한다.
- 1280×720 이상은 좌측 탐색, 좁은 화면은 상단 메뉴로 전환한다.
- 200% 확대에서도 가로 스크롤 없이 핵심 행위를 완료한다. 도면 캔버스만 자체 확대·이동을 허용한다.

## 2. SCR-001 지식 가져오기

**목표:** FN-001로 Excel 구조와 이미지 연결을 확인한 뒤 지식을 확정한다.

```text
┌ 지식 가져오기 ───────────────────────────────────────────────────┐
│ [Excel 선택]  저장된 프로파일 [선택 ▼]                           │
│ 파일: 오류사례_예시.xlsx   8.2MB   [미리보기 생성]                │
├───────────────────────────────────────────────────────────────────┤
│ 시트        사례ID 열   설명 열   원인 열   조치 열   이미지 연결 │
│ 기계오류    A           C         D         E         anchor 기준 │
│ 전기오류    A           B         D         F         주변 2열    │
├──────────────────────────────────┬────────────────────────────────┤
│ 행·셀 미리보기                   │ 연결 이미지·주변 문맥          │
│ [경고] 행 17: 설명 비어 있음     │ [이미지]                       │
│ 셀 C7: 용접부 치수 누락          │ anchor D7 · sheet 기계오류     │
├──────────────────────────────────┴────────────────────────────────┤
│ 92건 준비 · 경고 3건       [취소] [프로파일 저장] [가져오기 확정] │
└───────────────────────────────────────────────────────────────────┘
```

- **Primary action:** 가져오기 확정. 경고를 확인하지 않으면 비활성이다.
- **키보드:** 표 셀은 방향키, 이미지 상세는 Enter, 수정 취소는 Escape, 오류 요약으로 바로 이동하는 링크 제공.
- **상태:**
  - Loading: 파일 해시·관계 분석 단계와 취소 버튼.
  - Empty: 지원 형식과 예시 구조 안내.
  - Error: 파일 전체 오류와 행·셀 경고를 분리.
  - Success: 생성·갱신·건너뜀 수와 SCR-002 이동 버튼.
  - Denied: 암호화·크기 초과·XLS는 사유와 해결 방법 표시.
- **관련:** FR-001, FR-002, FN-001, API-001, API-002.

## 3. SCR-002 규칙 카탈로그

**목표:** FN-002의 후보를 검토하고 자동 판정에 사용할 규칙을 승인한다.

```text
┌ 규칙 카탈로그 ───────────────────────────────────────────────────┐
│ 상태 [Draft ▼] 분야 [전체 ▼] 검색 [____________] [+ 수동 규칙]  │
├──────────────────────────────┬────────────────────────────────────┤
│ □ ID     검사 필드   상태    │ 규칙 상세                          │
│   R-104  허용 공차   Draft   │ 출처: 사례 ERR-0142 · Excel C17   │
│   R-098  재질 규격   Approved│ 대상: 기계 / 치수                  │
│   R-077  레이어명    Inactive│ 연산자: max  값: 0.2  단위: mm    │
│                              │ 심각도: 높음                        │
│                              │ 예외: 상세도 유형 X                 │
│                              │ [변경 이력] [비활성] [승인]         │
└──────────────────────────────┴────────────────────────────────────┘
```

- **Primary action:** Draft 승인. 단위·출처·대상·심각도가 없으면 비활성이다.
- **키보드:** 표 행 이동 후 Enter로 상세, 상태 변경은 확인 대화상자와 포커스 복귀.
- **상태:** Empty는 지식 가져오기 연결, conflict는 최신 버전을 다시 읽고 차이를 표시, success는 상태와 새 버전 번호를 알림.
- **관련:** FR-003, FN-002, API-003, API-004.

## 4. SCR-003 도면 검사

**목표:** FN-003~FN-005와 FN-007을 시작하고 입력 품질·진행 상황을 이해한다.

```text
┌ 도면 검사 ───────────────────────────────────────────────────────┐
│ 프로젝트 [신규 설계 A ▼]                                        │
│ ┌───────────────────────────────────────────────────────────────┐ │
│ │ PDF 또는 DXF를 끌어놓거나 [파일 선택]                         │ │
│ └───────────────────────────────────────────────────────────────┘ │
│ 파일: panel-A.dxf · 12.4MB · DXF R2018                          │
│ 품질: XREF 정상 · 폰트 정상 · 단위 mm · 규칙 36개 적용 예정     │
│ 실행: CPU 기본 · 예상 2분 10초                                  │
│                                          [분석 시작]             │
├───────────────────────────────────────────────────────────────────┤
│ 현재 작업: 규칙 검사  ███████░░░  68%                           │
│ ✓ 입력 검증  ✓ 구조 추출  ● 규칙 검사  ○ 검색  ○ 개선 제안     │
│ [작업 취소]                                      [결과 먼저 보기]│
└───────────────────────────────────────────────────────────────────┘
```

- **Primary action:** 검증 통과 후 분석 시작.
- **키보드:** 파일 선택과 drop zone은 동일 동작, 단계 목록은 screen-reader live region이 과도하게 반복하지 않도록 단계 변경만 알린다.
- **상태:** queued 위치, running 단계, cancelling, failed 재시도, cancelled 새 분석, completed 결과 이동.
- **Denied:** DWG·암호화·상한 초과·XREF 누락은 사유와 변환/보완 안내를 제공한다.
- **관련:** FR-004~FR-007, FR-010, FN-003~FN-005, FN-007, API-005~API-009.

## 5. SCR-004 검사 결과

**목표:** FN-005~FN-009 결과를 도면 위치와 근거 중심으로 검토하고 내보낸다.

```text
┌ 검사 결과 ───────────────────────────────────────────────────────┐
│ panel-A.dxf  규칙 v12 · 모델 CPU-basic-1  [CSV] [Excel]          │
│ 필터 상태 [전체] 심각도 [전체] 유형 [전체]  검색 [___________]   │
├───────────────┬─────────────────────────────┬─────────────────────┤
│ 결과 목록     │ 도면 뷰어                   │ 근거·개선 제안      │
│ 위반  3       │       ┌──────────┐          │ 문제                │
│ 의심  5       │       │ 강조 ROI│          │ 허용 공차 초과      │
│ 정보부족 1    │       └──────────┘          │ 위치                │
│ ───────────   │ [−] 100% [+] [영역 맞춤]   │ DIMENSION #913      │
│ ● 공차 초과   │ 페이지/시트 A-101           │ 규칙 R-104          │
│ ○ 재질 확인   │ 좌표 x1200 y340             │ 사례 ERR-0142       │
│ △ 단위 불명   │                             │ 수정: ±0.2 확인     │
│               │                             │ [검토 메모________] │
└───────────────┴─────────────────────────────┴─────────────────────┘
```

- **Primary action:** 결과 선택과 근거 검토. 내보내기는 보조 action이다.
- **키보드:** 결과 목록 선택 시 뷰어·근거 제목을 알리고, `[`/`]`로 이전·다음 결과, `+`/`-` 확대. 캔버스 정보는 텍스트 위치 설명도 제공한다.
- **상태:** 규칙 결과만 준비, 검색 추가 중, 전체 완료, 검색 채널 실패, 원본 삭제됨, 결과 없음.
- **Empty success:** “검출된 항목 없음”과 검사 범위·적용 규칙 수를 표시하며 무오류를 보증하지 않는 문구를 둔다.
- **관련:** FR-007~FR-013, FN-005~FN-009, API-010~API-012.

## 6. SCR-005 설정·진단

**목표:** FN-009, FN-010으로 로컬 실행·모델·OpenAI·백업·삭제·진단을 통제한다.

```text
┌ 설정·진단 ───────────────────────────────────────────────────────┐
│ 실행 프로파일                                                    │
│ 감지: 8-core CPU · RAM 16GB · NVIDIA 없음                       │
│ 권장: CPU 기본  [모델 3.8GB 다운로드]                            │
├───────────────────────────────────────────────────────────────────┤
│ OpenAI 보완: 꺼짐 [설정]   키: 저장되지 않음                     │
│ 외부 전송은 분석 건별 미리보기와 동의가 필요합니다.              │
├───────────────────────────────────────────────────────────────────┤
│ 데이터 [암호화 백업] [복원 미리보기] [프로젝트 삭제]             │
│ 진단   [비식별 진단 번들 생성]                                  │
└───────────────────────────────────────────────────────────────────┘
```

- **Primary action:** 문맥에 따라 모델 설치, 백업, 진단 중 하나이며 파괴적 action은 Danger 영역에 분리한다.
- **키보드:** 대화상자는 포커스 trap·Escape 닫기·닫은 뒤 원래 버튼 복귀.
- **상태:** 모델 다운로드 진행·해시 실패·디스크 부족·오프라인, 키 저장 성공·실패, 백업 검증 오류, 삭제 확인.
- **삭제 확인:** 프로젝트명 재입력이 아니라 삭제할 데이터 범위 체크와 한 번의 명시적 확인을 사용한다.
- **관련:** FR-014~FR-016, FN-009, FN-010, API-013~API-016.

## 7. 반응형·확대 규칙

- 1024px 미만에서는 목록→뷰어→근거를 탭으로 전환하되 선택 상태를 보존한다.
- 표는 열 숨김보다 가로 스크롤과 고정 첫 열을 우선한다.
- 도면 하이라이트는 색뿐 아니라 패턴·번호·목록 연결선을 사용한다.
- 320 CSS px에서 핵심 action, 상태, 오류 설명이 겹치지 않아야 한다.
