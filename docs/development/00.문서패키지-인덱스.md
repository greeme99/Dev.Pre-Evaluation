## 1. 목적

이 패키지는 기계·설비 및 전기·계장 설계자가 Windows PC에서 PDF/DXF 도면을 사전 점검하는 로컬 웹앱의 승인 기준선이다. 문서는 요구사항에서 기능, 화면·API, 테스트까지 연결하며 제품 코드를 구현하거나 테스트를 실행했다고 주장하지 않는다.

## 3. 사용 및 변경 규칙

1. 식별자는 승인 후 재사용하지 않는다. 폐기된 항목은 `Deprecated`로 남긴다.
2. 요구사항 의미가 바뀌면 01 문서를 먼저 수정하고 추적되는 모든 문서를 같은 변경에서 갱신한다.
3. 품질 Gate를 낮추는 변경은 Product Owner, Technical Lead, QA Lead 모두의 검토를 받는다.
4. 실제 회사 도면, 자격 증명, 내부 주소와 고객 식별자는 문서 예시에 넣지 않는다.
5. 구현 중 증거가 필요한 결정은 담당 역할과 결정 Gate를 명시한다.

## 5. 용어

| 용어 | 정의 |
| --- | --- |
| 지식 사례 | Excel에서 가져온 오류 설명, 원인, 조치, 표, 이미지와 출처 셀의 묶음 |
| 규칙 후보 | 지식 사례에서 추출됐으나 사람이 승인하지 않은 검사 기준 |

| 골든셋 | 전문가 정답과 분리된 평가 분할을 포함하는 품질 검증 자료 |
| 실행 프로파일 | CPU 기본, GPU 가속 또는 명시적 OpenAI 보완 실행 설정 |
