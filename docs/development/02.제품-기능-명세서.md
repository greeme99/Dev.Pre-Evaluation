## 1. 제품 원칙

1. 규칙이 먼저 판정하고 AI는 근거를 찾고 설명한다.
2. 결과보다 원본 위치와 근거가 먼저 보인다.
3. 로컬 기능은 모델 다운로드와 외부 연결 없이도 사용할 수 있다.
4. 긴 분석은 단계별로 진행되고 중단 후 복구된다.
5. 위험한 동작은 삭제 범위나 외부 전송 내용을 먼저 보여준다.

## 3. 핵심 사용자 흐름

### Flow A: 지식 구축

1. 설계자가 SCR-001에서 Excel을 선택한다.
2. FN-001이 파일을 검증하고 시트·열·이미지 매핑을 미리 보여준다.
3. 설계자가 잘못된 매핑을 수정하고 확정한다.
4. 사례를 멱등 저장하고 가져오기 프로파일을 보관한다.
5. FN-002가 결정적으로 해석 가능한 규칙 후보를 `draft`로 생성한다.
6. 설계자가 SCR-002에서 단위·예외·심각도를 확인하고 승인한다.

### Flow B: 도면 사전 검토

1. 설계자가 SCR-003에서 PDF 또는 DXF를 업로드한다.
2. FN-003이 입력 품질을 검사하고 차단 사유 또는 예상 분석 프로파일을 표시한다.
3. FN-007이 작업을 큐에 넣고 FN-004가 구조·좌표·타일을 추출한다.
4. FN-005 규칙 결과가 먼저 SCR-004에 표시된다.
5. FN-006 검색과 FN-008 개선 제안이 뒤이어 결과에 추가된다.
6. 설계자는 근거와 위치를 확인하고 메모를 작성해 FN-009로 내보낸다.

### Flow C: OpenAI 보완

1. 설계자가 SCR-005에서 OpenAI 공급자를 설정한다.
2. 로컬 분석 결과 화면에서 보완 실행을 선택한다.
3. 앱은 전송할 비식별 텍스트와 이미지 타일을 미리 보여준다.
4. 설계자가 해당 분석 건에 동의한 경우에만 전송한다.
5. 실패 시 로컬 결과는 유지되고 전송 데이터는 폐기된다.

## 4. 기능 상세

### FN-001 Excel 지식 가져오기

- **입력:** `.xlsx`, 저장된 ImportProfile 선택 여부.
- **순서:** 시그니처·암호화·크기 검증 → 시트 탐색 → 열 후보 → 이미지 relationship·anchor 추출 → 주변 문맥 생성 → 미리보기 → 사용자 수정 → 확정.
- **출력:** KnowledgeCase, 원본 셀·이미지 ID, ImportProfile, 가져오기 결과 요약.
- **상태:** 업로드 중, 미리보기 생성, 수정 필요, 확정 중, 완료, 실패.
- **예외:** 필수 설명 열 없음, 깨진 relationship, 지원하지 않는 이미지 형식은 행·셀 단위 경고로 표시한다. 복구 불가능한 파일만 전체 실패시킨다.
- **완료 기준:** FR-001, FR-002 및 TC-001~TC-004 충족.

### FN-002 규칙 카탈로그

- **입력:** KnowledgeCase 또는 수동 규칙 입력.
- **순서:** 수치·단위·재질·규격·레이어 패턴 추출 → draft 저장 → 필드 검증 → 승인 또는 비활성.
- **출력:** RuleDefinition과 변경 이력.
- **상태 전이:** `draft → approved → inactive`; `inactive → draft`는 새 버전 생성으로만 허용한다.
- **예외:** 단위 없는 수치, 충돌 기준, 출처 없는 후보는 승인할 수 없다.
- **완료 기준:** FR-003, RULE-002, RULE-005, RULE-009 및 TC-005~TC-007 충족.

### FN-003 도면 입력·품질 검사

- **입력:** PDF 또는 DXF.
- **순서:** 확장자·MIME·매직 바이트 → 암호화 → 크기·페이지 → DXF 구조·XREF·폰트 → 실행 프로파일 예상.
- **출력:** ValidationReport, StoredFile 또는 차단 오류.
- **예외:** `.dwg`, 암호화, 상한 초과, 확장자 위장은 전체 거부한다.
- **완료 기준:** FR-004 및 TC-008~TC-010 충족.

### FN-004 PDF/DXF 정형 추출

- **PDF:** 벡터 텍스트 우선, 스캔은 OCR, 300 DPI 렌더, 1024px·25% 겹침 타일.
- **DXF:** modelspace/paperspace를 분리하고 LINE, LWPOLYLINE, CIRCLE, ARC, TEXT, MTEXT, DIMENSION, INSERT를 추출한다.
- **출력:** DrawingDocument, TextRegion, DrawingTile, transform matrix, 품질 점수.
- **예외:** 저해상도 PDF는 정보 부족 영역으로, XREF·필수 폰트 누락 DXF는 규칙 단계 차단으로 처리한다.
- **완료 기준:** FR-005, FR-006 및 TC-011, TC-012 충족.

### FN-005 승인 규칙 검사

- **입력:** DrawingDocument와 해당 도면 유형의 approved RuleDefinition.
- **순서:** 필드 선택 → 단위 정규화 → 예외 적용 → 연산자 평가 → 원본 좌표 근거 생성.
- **연산자:** required, equals, matches, min, max, range, allowed_values.
- **출력:** violation 또는 insufficient_information Finding.
- **예외:** 단위 불명, 신뢰도 임계 미만 추출, 적용 대상 불일치는 위반으로 확정하지 않는다.
- **완료 기준:** FR-007, RULE-001~RULE-005 및 TC-013~TC-015 충족.

### FN-006 텍스트·Pixel RAG

- **입력:** 도면 영역의 텍스트, 메타데이터와 타일 이미지.
- **순서:** SQLite FTS5/BM25 → Qdrant 텍스트 벡터 → RRF 결합 → 분야 필터 → 시각 벡터 검색 → Top-5 근거 구성.
- **출력:** RetrievedEvidence와 키워드·텍스트 벡터·시각 점수.
- **예외:** 모델 미설치 시 해당 채널만 건너뛰며 규칙 결과는 유지한다.
- **완료 기준:** FR-008, FR-009 및 TC-019~TC-021 충족.

### FN-007 영속 분석 작업

- **단계:** validate → extract → rules → retrieve → suggest → export_ready.
- **상태:** queued, running, cancelling, cancelled, failed, completed.
- **규칙:** PC당 running 1개, 추가 작업 FIFO; 단계 완료 시 체크포인트 저장.
- **복구:** 앱 재시작 시 마지막 완료 단계 다음부터 재개한다.
- **완료 기준:** FR-010, RULE-006 및 TC-016~TC-018 충족.

### FN-008 결과·개선 제안

- **표시:** 상태, 심각도, 신뢰도, 오류 유형, 하이라이트, 승인 규칙, 사례, 원본 위치.
- **제안 schema:** problem, inspect_location, suggested_change, evidence_ids, conditions_to_verify.
- **규칙:** AI가 규칙 결과를 격상·취소하지 않는다. 근거가 없으면 확인 질문만 반환한다.
- **완료 기준:** FR-011, FR-012, RULE-003 및 TC-022~TC-024 충족.

### FN-009 내보내기·백업

- **결과 내보내기:** 고정 열 순서 XLSX와 UTF-8 BOM CSV.
- **백업:** Argon2id 키 유도, AES-256-GCM 암호화, version manifest, 원본 포함 선택.
- **복원:** 패키지 검증 → 호환 버전 확인 → 충돌 미리보기 → 원자적 반영.
- **완료 기준:** FR-013, FR-014 및 TC-025~TC-028 충족.

### FN-010 실행 설정·삭제·진단

- **하드웨어:** CPU·RAM·NVIDIA GPU 감지 후 CPU/GPU 프로파일 추천.
- **모델:** 크기·라이선스·최소 사양·해시를 표시하고 설치·검증·삭제한다.
- **보안:** OpenAI 키는 Windows 자격 증명 관리자에 저장한다.
- **삭제:** 프로젝트의 DB, Qdrant, FTS, 원본, 타일, 결과, 작업 상태를 함께 제거한다.
- **진단:** 앱·모델·파서 버전, 오류 코드, 단계 시간만 포함한다.
- **완료 기준:** FR-015, FR-016, RULE-007~RULE-009 및 TC-029~TC-032 충족.
