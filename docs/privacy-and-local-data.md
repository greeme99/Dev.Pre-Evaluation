# 로컬 데이터 보존 및 개인정보 보호 정책 (TC-108, NFR-008, NFR-009)

본 문서는 **Dev.Pre-Evaluation** 시스템이 엔지니어링 도면 및 검토 데이터의 기밀성을 어떻게 보장하고 관리하는지 설명합니다.

---

## 1. 데이터 보안 기본 원칙 (Security Principles)

1. **오프라인 우선 (Zero-Outbound by Default)**
   - 시스템은 외부 인터넷 연결 없이 100% 로컬 CPU 환경에서 동작합니다.
   - 외부 AI 보완(OpenAI) 기능을 사용자가 명시적으로 활성화하고 동의하지 않는 한, 어떠한 도면 데이터나 메타데이터도 외부 네트워크로 송출되지 않습니다.
2. **로컬 루프백 전용 바인딩 (`127.0.0.1`)**
   - 웹 서버는 `0.0.0.0` 바인딩을 엄격히 거부하며 오직 `127.0.0.1:17841` 로컬 루프백에만 바인딩됩니다. 동일 로컬 네트워크(LAN) 상의 다른 PC나 외부 침입자가 접근할 수 없습니다.

---

## 2. 데이터 저장 구조 및 보존

| 데이터 분류 | 저장 위치 | 암호화 및 보호 |
| --- | --- | --- |
| **메타데이터 & 규칙 DB** | `%LOCALAPPDATA%\DevPreReview\dev_pre_review.db` | 사용자 계정 ACL 보호 SQLite |
| **도면 렌더 타일 & 캐시** | `%LOCALAPPDATA%\DevPreReview\artifacts\` | 비식별 UUID 기반 파일명 격리 |
| **실행 진단 로그** | `%LOCALAPPDATA%\DevPreReview\logs\` | 절대 경로/API 키 마스킹 |
| **외부 백업 패키지** | 사용자가 지정한 `.dprb` 파일 | Argon2id 키 유도 + AES-256-GCM 암호화 |

---

## 3. 원문 마스킹 진단 번들 (Sanitized Diagnostics)

- 시스템 문제 발생 시 지원팀에 전달하기 위한 진단 번들 생성 시:
  - 사용자 홈 디렉터리, 파일 절대 경로(`C:\Users\...`, `/Users/...`)는 모두 `[REDACTED_PATH]`로 마스킹됩니다.
  - API 토큰(`sk-...`)은 모두 `[REDACTED_KEY]`로 마스킹됩니다.
  - 도면 원문 텍스트 및 CAD 엔티티 내용은 진단 번들에 일절 포함되지 않습니다.
