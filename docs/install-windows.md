# Windows 설치 및 실행 가이드 (TC-106)

본 문서는 Windows 10/11 환경에서 **Dev.Pre-Evaluation (개발 도면 사전 검토 자동화 시스템)**을 설치, 실행 및 업데이트하는 절차를 안내합니다.

---

## 1. 시스템 요구사항 (System Requirements)

| 항목 | 최소 사양 | 권장 사양 |
| --- | --- | --- |
| **운영체제** | Windows 10 64-bit (1909 이상) | Windows 11 64-bit |
| **CPU** | 4-Core x86_64 | 8-Core x86_64 |
| **메모리 (RAM)** | 8 GB | 16 GB 이상 |
| **디스크 여유 공간** | 1.5 GB | 3.0 GB 이상 (SSD 권장) |
| **GPU** | 불필요 (CPU 기반 100% 동작) | - |
| **네트워크** | 오프라인 완전 동작 (인터넷 불필요) | - |

---

## 2. 설치 절차 (Installation)

1. 최신 배포 릴리스에서 `DevPreReview-Setup-x64.exe` 설치 관리자를 다운로드합니다.
2. 다운로드한 설치 프로그램을 실행합니다.
   - **권한 안내**: 본 설치 프로그램은 `PrivilegesRequired=lowest`로 구성되어 있어 **관리자 권한(UAC) 없이** 일반 사용자 계정으로 설치할 수 있습니다.
   - 기본 설치 경로: `%LOCALAPPDATA%\Programs\DevPreReview` 또는 `C:\Program Files\DevPreReview`
3. 설치 완료 시 바탕화면 및 시작 메뉴에 바로가기가 생성됩니다.

---

## 3. 실행 및 단일 인스턴스 관리 (Execution)

1. 바로가기 또는 `DevPreReview.exe`를 실행합니다.
2. 시스템은 로컬 주소 `http://127.0.0.1:17841`에 바인딩되며 기본 웹 브라우저가 자동으로 열립니다.
3. **단일 인스턴스 보호**:
   - 이미 프로그램이 실행 중인 상태에서 다시 실행할 경우, 중복 프로세스를 띄우지 않고 기존 실행 창으로 포커스 전환합니다.
   - 만약 다른 프로그램이 17841 포트를 점유하고 있는 경우 충돌 오류를 안전하게 보고하고 종료합니다.

---

## 4. 데이터 보존 및 프로그램 제거 (Data Retention & Uninstall)

- **데이터 저장 위치**: 모든 사용자 프로젝트, 검토 이력, 규칙 카탈로그, SQLite DB는 `%LOCALAPPDATA%\DevPreReview`에 안전하게 격리 보관됩니다.
- **버전 업데이트**: 상위 버전 설치 시 기존 데이터베이스를 자동으로 감지하여 Alembic 마이그레이션을 통해 스키마를 안전하게 보존·갱신합니다.
- **프로그램 제거**: 제어판 '프로그램 추가/제거'에서 제거 시 애플리케이션 실행 파일만 삭제되며, 사용자의 소중한 검토 이력 및 DB는 삭제되지 않고 유지됩니다.
